一、本站是什么

CareerSafari 是一个求职信息整理与结构化归档的技术演示项目。 它把公开可见的招聘信息（企业招聘官网、官方公众号、招聘平台、第三方转载等） 采集下来，整理成带来源可信度标注的结构化岗位档案，方便求职者对比与查阅。

本站不提供招聘服务。 不发布招聘岗位、不接收简历、不提供投递或撮合功能、不开展职业中介活动，也不向求职者收取任何费用。 本站仅对已公开的招聘信息做整理与展示，性质上等同于个人笔记与文献索引。

二、数据来源可信度分级

每条岗位记录都标注了来源等级，供你判断信息可信度：

等级含义说明
P1 企业官方 企业招聘官网、官方公众号。可信度最高，但官方通常不披露薪资。
P2 招聘平台 BOSS 直聘、猎聘、智联等平台的公开页面。
P3 转发 / 聚合 高校就业网、第三方聚合站的转载。信息往往最全（含薪资区间），但是二手来源，需交叉核对。
P4 UGC 小红书、知乎、面经等用户内容。参考性最强、可信度最低。

每条记录同时展示采集日期与原始链接，你可以据此回溯核实。

三、准确性、时效性与完整性免责

  • 可能已过期。招聘状态随时变化，标注为「在招」不代表仍在招，请以用人单位官方渠道为准。
  • 截止日期可能滞后。截止日期按「单岗位披露 > 页面级公告 > 按岗位类型推算」的优先级回填，存在推算成分，仅供参考。
  • 薪资数据尤其不可靠。官方页普遍不披露薪资，站内出现的薪资多为第三方转载区间，仅供量级参考。
  • 抽取可能有误。字段由自动化流程配合人工校准生成，可能存在遗漏或偏差。以原始链接的原文为准。
  • 不构成任何建议。本站不构成求职建议、法律意见或投资建议。因使用本站信息产生的任何后果，本站不承担责任。

四、权利与侵权处理

站内岗位信息的著作权归原发布方所有。本站对相关信息的使用限于「为说明问题而引用」与信息索引， 并始终保留原始链接与来源标注。若你是权利人或用人单位，认为某条内容的使用方式不当，或希望删除某条记录， 请通过下方方式联系，我们会在核实后及时删除。

五、隐私说明

  • 本站没有账号体系，不收集姓名、手机号、简历等任何个人身份信息。
  • 浏览器本地存储（localStorage）仅用于保存一个「管理令牌」，不会上传，清除浏览器数据即删除。
  • 服务端日志会记录访问 IP 与请求路径，用于安全防护与限流，不用于任何其他用途。

六、技术说明

本项目为开源技术演示：后端 FastAPI + SQLite，前端零依赖单页应用， 采集产物以 JSON 落盘作为唯一数据源头。查看源码与技术文档请访问仓库： github.com/BruceLi012/CareerSafari。
